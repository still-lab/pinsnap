# 贴图生命周期用例（手工验收）

对齐 Snipaste 语义。M3 打勾。

| # | 步骤 | 期望 |
|---|---|---|
| 1 | 贴出 A、B 两张 | 均置顶可拖动 |
| 2 | 关闭 A | A 消失；再贴图热键可恢复 A（在恢复栈内） |
| 3 | 销毁 B | B 不可恢复；文件删除 |
| 4 | 隐藏全部 | A/B 都看不见；再按显隐恢复，关闭栈不变 |
| 5 | Free 已有 3 张再贴 | 拦截并引导 Pro |
| 6 | Pro 开穿透 | 点击穿透到下层；托盘可取消全部穿透 |
| 7 | 重启 App（Pro） | 会话位置与图片恢复 |
| 8 | 复制纯色 `#FF0000` 再贴 | 色卡贴图 |
| 9 | 复制一段文本再贴 | 文本渲染为图贴出 |
