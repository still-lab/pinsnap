# PinSnap UI 规格（线框级）

状态：线框 / 信息架构，非正式视觉稿。

## 设计立场（对标 iShot / Snipaste）

这类产品的界面哲学是：**几乎没有「管理界面」**。

| 对 | 错 |
|---|---|
| 状态栏一枚图标常驻 | Dock 常驻、主窗口仪表盘 |
| 点击图标 = 执行任务（截图/贴图/…） | 先进入设置中心再找功能 |
| 主路径靠全局快捷键 | 依赖多层菜单导览 |
| 截图遮罩 / 贴图 = 临时任务表面，用完即走 | 常驻「图库 / 工作台 / 项目」 |
| 设置极少打开，藏在图标菜单最下方 | 设置项铺满、开机弹窗教程 |

**iShot / Snipaste 共性**

- 用户感知到的 UI ≈ **菜单栏图标 + 快捷键 +（临时）遮罩/贴图**
- 偏好设置存在，但是**逃逸舱**，不是日常表面；熟练用户甚至可隐藏托盘图标、只靠热键
- 截图过程中的工具条是**情境 UI**（选完区才出现），不是独立 App 模块页
- 没有「首页」「任务列表」「复杂侧栏」

**PinSnap 因此约束**

1. **唯一常驻控件**：菜单栏图标（可后续提供「隐藏图标、仅热键」选项，对标 iShot）。  
2. **图标菜单要短**：只放动作；设置 / Pro / 退出沉底。  
3. **不做管理型主窗**：不设图库主界面、不设仪表盘；贴图库若做，也从菜单一项弹出轻量列表即关。  
4. **设置 = 窄偏好窗**：只保留热键、存储、少数 Toggle、Pro、关于；禁止说明段落。  
5. **无功能导览轮播**；权限也不做自定义引导窗，未授权只跳系统设置。 

---

原则（文案与实现）：短标签；无解释性长文；系统控件优先；截图层 AppKit，设置/商店 SwiftUI。

## 0. 全局

### 0.1 窗口与层级

| 表面 | 类型 | 是否常驻 | 说明 |
|---|---|---|---|
| 菜单栏图标 | `NSStatusItem` | **唯一常驻** | 点击出动作菜单；或单击直接截图（见 §1 策略） |
| 截图遮罩 | 全屏 `NSPanel` | 临时 | 任务中；Esc/出口后销毁 |
| 截图工具条 | 选区附属 | 临时 | 情境 UI |
| 贴图 | `NSPanel` × N | 用户决定 | 对照用「钉」，不是管理页 |
| 设置 | 窄偏好窗 | 按需 | 从菜单打开，关了就无 |
| 升级 Pro | 小窗 | 按需 | 事件触发，非日常 |

**明确不做的表面：** App 主窗口、Dock 常亮（默认 `LSUIElement`）、启动欢迎页、功能介绍轮播、复杂「资源库」浏览器作为默认首页。

### 0.2 密度与尺寸（建议）

| 元素 | 规格 |
|---|---|
| 菜单栏图标 | 模板图 16×16 / 18×18＠2x |
| 截图工具条按钮 | 32×32 热区，图标 16–18 |
| 贴图最小边 | ≥ 48 pt（缩略模式可更小，M3） |
| 设置窗 | 宽 **420–480**（刻意窄，不像「控制台」） |
| 引导/升级窗 | 宽 360–400 |

### 0.3 颜色（线框阶段）

不定品牌色。开发默认：

- 遮罩：黑 ~45–55% 透明  
- 选区边框：白 2pt + 外描边淡黑  
- 窗口吸附高亮：系统强调色 2pt  
- 工具条：系统 `NSVisualEffectView`（HUD，轻）  
- 穿透开启：贴图边框虚线或角标「穿透」

### 0.4 文案规则

- 按钮：动词或名词，≤ 4 字（中文）/ 1–2 词（英文）  
- 不写「不会上传…」类说明；隐私仅「关于」里一个链接  
- Toast：一行，自动消失

## 1. 菜单栏（产品主入口）

### 1.1 推荐交互策略

二选一（v1.0 锁定 **A**，更贴近「点一下就干活」）：

| 策略 | 行为 | 备注 |
|---|---|---|
| **A** | 左键单击图标 = 立即开始截图；右键 = 动作菜单 | — |
| **B（锁定）** | **左键始终出菜单**；菜单内选截图等动作 | 发现性更好；当前实现 |

热键仍是重度用户主路径；图标服务「想起来点一下」的场景。

### 1.2 动作菜单（右键 / ⌃+点；策略 B 时为左键）

保持极短，**上动作、下逃逸**：

```
[图标]
├ 截图            F1
├ 延时截图        ⌘T
├ 贴图            F3
├ 显示/隐藏贴图    ⌘H / ⌘⇧H
├ ────────
├ 设置…                    ← 逃逸舱
├ 升级 Pro…                ← Free；Pro 用户可改为「Pro」只读或「管理订阅…」
└ 退出 PinSnap
```

**禁止**往菜单里堆：历史列表、长截图、OCR、录屏、帮助中心、账号中心（v1.0）。  
后续能力优先 **热键 / 截图工具条情境入口**，而不是菜单膨胀。

### 1.3 图标状态

| 状态 | 表现 |
|---|---|
| 正常 | 默认模板图标 |
| 截图中 | 保持默认（不闪、不换复杂动画） |
| 未授权 | 截图意图时深链「系统设置 → 屏幕录制」；本进程最多一次，无自定义引导窗 |
| 可选后期 | 设置项「隐藏菜单栏图标」（仅热键），对标 iShot |

## 2. 权限（无引导窗）

**策略：** Preparing 发现无屏幕录制权限 → `openSystemSettings()`，不弹 App 内引导窗、不堆菜单项。  
授权后用户再次触发截图即可；不做自动重试窗。

## 3. 截图 Overlay

### 3.1 布局

```
┌────────────── 全屏遮罩 ──────────────┐
│ ████████████████████████████████████ │
│ ████┌────────选区────────┐██████████ │
│ ████│                    │██████████ │
│ ████│   (清晰原图像素)     │██████████ │
│ ████│                    │██████████ │
│ ████└────────────────────┘██████████ │
│ ████     ┌──工具条──┐     ██████████ │
│ ████████████████████████████████████ │
└──────────────────────────────────────┘
```

- 选区外变暗；选区内显示截帧原图（或实时屏）。  
- 悬停窗口时：该窗矩形高亮，单击吸附为选区。  
- **v1.0 选区不跨屏**：移到屏边吸住。  

### 3.2 选区尺寸徽章（可选 P1）

选区右下或中上：`1920 × 1080`（逻辑 pt 或 px，设置可切；v1.0 先显示 px）。

### 3.3 工具条（选区确认后出现）

| 顺序 | 功能 | Tooltip 中/英 |
|---|---|---|
| 1 | 矩形 | 矩形 / Rect |
| 2 | 椭圆 | 椭圆 / Ellipse |
| 3 | 箭头 | 箭头 / Arrow |
| 4 | 画笔 | 画笔 / Pen |
| 5 | 马赛克 | 马赛克 / Mosaic |
| 6 | 文字 | 文字 / Text |
| — | 分隔 | |
| 7 | 撤销 | 撤销 / Undo |
| — | 分隔 | |
| 8 | 复制 | 复制 / Copy |
| 9 | 保存 | 保存 / Save |
| 10 | 贴图 | 贴图 / Pin |
| 11 | 关闭 | 关闭 / Close |

Free 基础标注仅开放与 A-01–03 对应的工具；序号/高亮等 Pro 工具 M3 再露（未解锁可灰显点按出升级）。

### 3.4 快捷键（Overlay 内，线框注明）

| 键 | 行为 |
|---|---|
| Esc | 取消回 Idle |
| Enter / ⌘C | 复制并结束（成功） |
| ⌘S | 快捷保存（快捷目录 → 默认目录 → 回落面板） |
| ⌘⇧S | 另存为（面板；目录/格式跟设置） |
| Space | 显示/隐藏工具条（可选） |
| 单键 R/E/A/… | 切换工具（设置可改，M3） |

### 3.5 放大镜 / 取色（P1，M3）

光标旁小窗：放大像素 + 下方色值 `＃RRGGBB`。  
键 `C` 复制色值（格式跟随设置）。

## 4. 贴图窗口

### 4.1 外观

```
┌─(可选细边框)─┐
│             │
│   图像内容    │
│             │
└─────────────┘
```

- 默认无大标题栏；拖动点按图像区域。  
- 滚轮：缩放；空格+滚轮：透明度。  
- Free 角标：不强制；超额在**创建时**弹窗，不在贴图上打水印。  

### 4.2 右键菜单

```
标注          ← 唤出贴图底部标注工具条；完成写回图像
复制
保存…
────────
透明度
────────
关闭
销毁
```

（穿透为日后 Pro，当前菜单不展示。）

### 4.3 穿透 HUD

**暂缓。** 日后 Pro 再做：Toast + 菜单「取消全部穿透」。

### 4.4 显隐

⌘H：全部隐藏。⌘⇧H：全部显示。隐藏时菜单栏图标不变（或轻微淡化，可选）。

## 6. 设置（逃逸舱，非主界面）

**定位：** 极少打开的窄偏好窗。默认用户应**从不需要**为了截一张图而进入设置。

信息架构保持少页、少行：

### 6.1 通用

| 行 | 控件 | 绑定 |
|---|---|---|
| 取色格式 | 分段 HEX · RGB（默认 HEX） | `pinsnap.colorFormat` |
| 禁用快捷键 | Toggle（默认开；与状态栏菜单同步） | `pinsnap.hotKeysDisabled` |

不加「语言」行（跟随系统本地化即可）。  
暂不开放：开机启动、隐藏菜单栏图标、外部激活取消截图（功能就绪后再加）。

布局：窗约 560×460；左侧短导航 ~132pt；右侧分组 Form，行距与区块间距偏松；跟随系统浅色/深色。

### 6.2 快捷键（可录制改绑）

分组：**全局** / **截图中**。行右侧为录制钮；冲突时旁标红字「冲突」。页脚「恢复默认」。

| 行 | 默认可改 | 说明 |
|---|---|---|
| 截图 | F1 · 可改 | 全局 |
| 上次区域 | 跟随截图键×2 | 只读，不单独录 |
| 延时截图 | ⌘T · 可改 | 全局 |
| 贴图 | F3 · 可改 | 全局 |
| 隐藏贴图 | ⌘H · 可改 | 全局 |
| 显示贴图 | ⇧⌘H · 可改 | 全局 |
| 快捷保存 | ⌘S · 可改 | Overlay |
| 另存为 | ⇧⌘S · 可改 | Overlay |
| 取色复制 | C · 可改 | Overlay |
| 取色切换 | Tab · 可改 | Overlay |
| 选区微调 | ←↑↓→ | 固定，不可改 |

录制：点击后按新键写入；Esc 取消。状态栏菜单右侧键位文案跟随绑定。  
冲突检测：App 内重复绑定 + Carbon 注册失败。不做其它 App 占用扫描。  
不展示「截图并复制 / 并保存」（无独立热键）。

### 6.3 存储

| 行 | 控件 | 绑定 |
|---|---|---|
| 默认文件夹 | 路径摘要 + `选择…` | 书签 `pinsnap.defaultSaveDirectory` |
| 快捷保存文件夹 | 路径摘要 + `选择…` | 书签 `pinsnap.quickSaveDirectory` |
| 格式 | Picker PNG / JPEG（默认 PNG） | `pinsnap.saveFormat` |
| 文件名模板 | 单行文本 | `pinsnap.filenameTemplate` |
| 打开保存目录 | 按钮 | 打开默认目录（无则 Downloads） |
| 清空上次区域 | 按钮 | `clearCaptureHistory()` |

### 6.4 Pro

本轮搁置：不进设置侧栏。升级仍可由状态栏菜单打开独立窗（§5.2）。

### 6.5 关于

| 行 |
|---|
| 版本号 |
| 隐私政策（链接） |
| 使用条款（链接） |

**设置里不做：** 账号体系、云同步面板、教程、changelog 长文、功能开关墙（十几个 Toggle 林立）、语言切换。

## 7. Toast / 空状态

| 场景 | 文案 |
|---|---|
| 复制成功 | `已复制` |
| 保存成功 | `已保存` |
| 剪贴板不可贴 | `无法贴图` |
| 需要权限 | `需要屏幕权限` |
| 穿透开/关 | `穿透已开` / `穿透已关` |

无空状态长文；贴图为 0 时显隐快捷键无操作即可。

## 8. 关键流程线框（ASCII）

### 8.0 日常心智（无管理页）

```
菜单栏图标 ──左键──► 截图遮罩 ──出口──► 消失
     │
     └─右键菜单──► 贴图 / 显隐 / 设置(少) / 退出
全局热键 ─────────────────────────────► 同上任务表面
```

用户不应感到「打开了某个 App」；只感到「截一下 / 钉一下」。

### 8.1 截 → 复制

```
菜单栏左键/F1 → [权限?] → 遮罩框选 → 工具条(可选标注) → 复制 → 遮罩关闭
```

### 8.2 截 → 贴

```
框选 → 贴图 → 遮罩关闭 → 桌面多一张 Pin
```

### 8.3 剪贴板贴

```
F3 → 解析剪贴板 → 成功则 Pin / 失败 Toast「无法贴图」
```

### 8.4 升级

```
第4张贴图 or 菜单「升级 Pro」→ 升级页 → StoreKit → Gate 刷新
```
