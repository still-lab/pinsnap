# PinSnap 产品需求（已决议摘要）

完整对标分析见会话画布；本文为仓库内可执行摘要。

## 一句话

PinSnap 是菜单栏常驻的 Mac 截图贴图工具：用户主动截屏，标注后复制/保存，或钉在桌面置顶对照；本地处理；可订阅或买断解锁 Pro。仅 Mac App Store。

## 锁定参数

| 项 | 决议 |

| 显示名 | PinSnap |
| 中文副标题 | 截图与贴图 |
| Bundle ID | `app.pinsnap.macos` |
| 最低系统 | macOS 13.0 Ventura |

## v1.0 范围

**做：** 区域/窗口截图、多屏 Retina、基础标注、贴图置顶（缩放/透明）、剪贴板贴图（图）、StoreKit。无权限时深链系统设置即可，**不做自定义权限引导窗**。

**Pro 在 v1.0 尽量带上：** 关闭/销毁/隐藏语义、剪贴板文/色、延时等 P1。

**明确不做进 v1.0：** 权限引导窗、贴图分组、截图历史回放、贴图穿透、会话恢复、捕捉光标、OCR、长截图、录屏、AX 元素吸附、超级截屏、屏幕触发角。

## 非目标

- 控制第三方窗口置顶/透明度
- 默认上传截图
- Windows / Linux 首发
- Dock 主窗口 / 管理型首页 / 功能导览轮播（形态 = 菜单栏工具）
- 自定义权限引导窗（只跳系统设置）
- 贴图分组 / 截图历史列表
- 贴图穿透（暂缓；日后 Pro）
- 会话恢复（退出/崩溃后不恢复贴图）
- 捕捉光标（截图不含鼠标指针）

## 成功截图定义

以下任一完成即「成功」：

1. 复制到剪贴板  
2. 保存到文件  
3. 贴到屏幕  
4. 另存为对话框确认  

## 贴图生命周期（对齐 Snipaste）

| 操作 | 行为 |
|---|---|
| 关闭 | 进入可恢复栈（容量有限） |
| 销毁 | 不可恢复，删持久化 |
| 隐藏全部 | 不进关闭栈，可再显示 |
